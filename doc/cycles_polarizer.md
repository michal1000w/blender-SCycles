# Glass linear polarizer

The Glass **Polarizer** checkbox enables an ideal absorbing linear analyzer on
transmission. **Polarizer Angle** rotates its pass direction in the object's
local XY plane: `cos(angle) X + sin(angle) Y`. The object transform carries this
physical axis to world space. Flipping a face normal does not reverse its angle.
This convention makes opposite faces of a closed slab share one physical axis.

The coherent vector model transports complex Jones fields for the existing
three independent world-dipole source modes. At each filtered interface it
projects the incoming field, applies flux-normalized Fresnel transmission,
and projects into the outgoing pass direction: `P_out T P_in`. Its reverse
is the transpose of its forward matrix; each projector is passive. Reflection
is unchanged. This is an ideal reciprocal dichroic analyzer coincident with the
interface, rather than a prediction of a particular commercial coating.
An index-matched pane (`IOR=1`) is a two-sided thin analyzer with no refracting
medium boundary. Two parallel matched analyzers transmit half of unpolarized
power; crossed analyzers transmit zero; a relative angle θ gives `cos²(θ)/2`.
An ordinary refracting slab additionally includes Fresnel transmission losses.

This filter acts on fields, not on an RGB cosine multiplier. Coherent RGB
radiometry retains its documented RGB-envelope source/detector model; the
coherence wavelength controls propagation phase, and this does not imply a
monochromatic reflectance reconstruction. Native camera and light paths carry Stokes polarization; the v42 renderer
checks below validate ordinary photographic filter response within the stated
substrate model.

Standalone implementation checks are recorded in
`build/tests/performance/coherent_polarizer_v41/results.json`: 500 projector,
actual two-face field/geometry, Malus, Brewster glare, interface reciprocity and oblique-axis
checks in each strict/fast CPU mode, plus 70 ownership checks in each mode.
These are numerical core checks; renderer and editable-demo acceptance are
separate gates. The matched substrate's expected incident side is a wildcard,
while its primitive sequence and reflection/transmission events still match
exactly for estimator ownership.

## Native photographic transport: implementation scope and current gate

The native integration carries per-channel Stokes polarization along camera and
light paths. Camera paths carry the adjoint detector response; BDPT light paths
carry the forward source state. BSDF mixtures combine matrices in the same
continuous or discrete measure as their sampling PDF. NEE, camera-visible
emission, light-path connections and solved MNEE interface chains contract these
states. Path guiding changes the proposal rather than the polarization model.
The feature is disabled by default, and an ordinary Transparent closure preserves
polarization. Photon Mapping currently rejects scenes containing an enabled
Glass polarizer because its stored photons do not carry this state.

For an uncoated physical dielectric interface, the single-facet reflection and
transmission matrices use the complex s/p Fresnel coefficients, including TIR
phase. The ideal linear analyzer applies reciprocal incoming and outgoing
projectors on transmission; it does not attenuate Glass reflection. Diffuse
scattering depolarizes. Native multiple-scattering compensation, diffraction
returns, nonphysical generalized Fresnel settings, and coated/custom substrates
use an explicit **Fast depolarizing substrate approximation** before the filter
projectors. Their spectral and scalar energy still comes from the existing
closure, but this approximation does not predict polarization generated by a
real thin-film stack or a grating. A straight diffraction transmission atom
preserves polarization. This is a linear polarizer, not a circular photographic
polarizer (CPL); no quarter-wave retarder is modeled.

The Metal shader-coupling report
`build/tests/python/native_polarizer_shader_prism_metal_v42/report.json`
records a remaining blocker: positive-depth matched-index grating filters
produce means approximately `.58` instead of `.5`, although the same CPU cases
pass. The six ordinary/zero-depth cases pass. Joint Metal diffraction/filter
coupling is not accepted until this discrepancy is resolved; its gates are
unchanged.

The coherent Jones renderer matrix is a separate 48-case gate. It is still
running at this documentation checkpoint; its oracle owner records the final
result separately. Numerical core validation is not presented as its completion.

The v41 black-output failure remains preserved in its original SVM/Metal
reports. Its confirmed cause was SVM stage eligibility: the new global transport
feature bit incorrectly prevented the Glass closure node from being emitted.
The v42 compiler excludes that bit from stage eligibility while retaining it
in scene transport features. The earlier cube shader-integration report also
remains preserved: its unfiltered baseline lost two individual samples at a
shared face-triangle edge. A closed triangular-prism fixture, with side faces
outside the measurement region, passes the same gates. This is fixture evidence,
not a claim that a general native cube intersection defect was established.

Unsupported cases fail explicitly: Photon Mapping; a rough, index-matched Glass
polarizer with effective thin film (including linked inputs that cannot establish
otherwise); and linked filter parameters on a declared coherent connector patch.
Use a smooth coated interface, no film, or a constant nonmatched IOR for the
rough-film limitation. Coherent filtering requires the vector source model;
scalar coherent mode does not model polarization. Eevee's Glass shader ignores
the Cycles-only filter sockets. No circular-retarder, commercial-coating or
universal wave-scattering accuracy is claimed.

The separate actual-closure test
`build/tests/performance/polarizer_payload_rough_matched_fixed_v41/results.json`
passed 117 checks of native sampling, mixed diffuse/discrete measures, rough
matched-index transmission, nearby nonmatched indices, metadata capacity and
transactional failure. These isolate closure behavior and capacity; they supplement the renderer gates above.
