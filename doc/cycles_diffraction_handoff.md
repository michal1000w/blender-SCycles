## How to use the implemented features

The Glass BSDF exposes `Polarizer` (default OFF) and `Polarizer Angle` in radians. Enable the checkbox for a linear photographic filter. Its physical axis is object-local `cos(angle) X + sin(angle) Y`, transformed to world space and projected transverse to propagation. Rotate the object to rotate the physical filter; the angle socket offers local rotation. Front/back normal reversal does not reverse the intended pass axis. The ideal IOR1 film provides the clean Malus tests; a physical refractive Glass filter also retains its Fresnel response. Reflection is unchanged by the transmission analyzer. Do not claim polarizer support for photon mapping: the unsupported path is explicitly guarded.

Coherent point sources need a positive coherence group, wavelength, coherence length and declared phase. Same-group sources interfere; different groups add intensities. Source powers in acceptance optics are explicitly 1 mW, not an exposure correction. Select vector polarization for the tested physical dipole/Jones reference. Enable coherent specular connections and tag actual objects as declared interfaces/detectors. The serialized mode enum remains `FACET_SINGLE_REFLECTION`, despite the UI now describing streamed mirror facets and supporting `coherent_max_interface_events=2`. This naming is historical, not evidence that two reflections are disabled. `BOUNDED` remains the default mode and uses the existing finite path inventory.

The streamed mode handles declared finite flat ideal-white mirror triangles: direct, all one-reflection paths, and ordered two-reflection paths when the event budget is 2. Meshes, separate objects and linked mesh instances are tested. There is no 64-facet inventory ceiling for this mode; two-reflection work scales quadratically with eligible facets, so large meshes can be expensive. Geometric facets are not a smooth-wave curved-surface model. Current validation isolates the first Lambertian detector with diffuse bounce budget 0. Total, glossy, transmission and emitter budgets still constrain physically admitted routes.

## Physics model and unfinished support

The references use geometric stationary optical paths, vector world-dipole fields, signed Jones/interface transport, optical carrier phase, and the existing Gaussian coherence envelope. The streamed estimator shares one Gaussian draw per group/sample, yielding the intended ensemble pair factor `exp(-0.5*(OPD/Lc)^2)`. This is an RGB-envelope/carrier model, not a complete broadband spectral mutual-coherence calculation. Small positive coherence lengths below the explicit supported floating-point range are rejected rather than silently flushed. Compensated phase arithmetic fixes the previously identified large-OPD/tiny-Lc loss of fractional cycles.

Supported and validated: the named native polarizer cases; bounded declared planar/sphere histories; streamed finite ideal mirrors through at most two reflections. Unsupported or unproven: arbitrary closed-mesh refraction, overlapping/nested dielectric media, general smooth/rough curved paths, arbitrary longer chains, volume transport, coherent motion, photon mapping and general wave diffraction at mesh edges. Native render support and coherent analytic connector support are separate capabilities. A scene may render natively while remaining unsupported for the coherent inventory. Coherent specular connectors currently require Metal; a CPU attempt is an unsupported-backend rejection, not a physics failure.

Photographic OFF disables the global polarization path and uses legacy scalar dielectric transport; ON enables polarization scene-wide. Background differences can therefore include changes across multiple Glass bounces. Do not interpret the photographed ON/OFF ratio as an isolated ideal analyzer transmission measurement. Finite-area Brewster illumination leaves physically expected residual glare. The gallery’s ROI ratios are descriptive, not post hoc acceptance gates.
