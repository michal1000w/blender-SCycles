# Principled MultiGGX diffraction

The fast model now splits arbitrary Metallic and Transmission Weight into three explicit components: F82 metallic reflection, generalized-Schlick dielectric reflection, and two-sided dielectric transmission with a matching first-event cache. SVM and OSL route each component to its own reciprocal diffraction return. Base Color and material weights can vary at runtime. Zero depth and disabled diffraction preserve the native path.

Metallic and dielectric reflection share the geometry-only one-sided directional albedo cache, including anisotropy and tangent orientation. Their return amplitude uses their own spectral Fresnel average; dielectric reflection does not recycle the missing energy as an unconditional white return. The layer albedo includes the integrated return before attenuating the lower diffuse/subsurface layer. This also improves layer and guiding estimates for the existing cached Glossy/Metallic path; their sample/eval formulas remain unchanged.

The transmissive component uses a reciprocal etendue return. Its first-event model is isotropic, matching the existing Principled solid transmission closure. Arbitrary transmission weights and bounded spectral Base Color tint are supported. Bare interfaces support runtime Specular Tint and constant Cauchy dispersion: two scalar F0 endpoint caches reconstruct the native generalized powers exactly before ordinary direction/wavelength interpolation. The first event retains the native d-line F0 tint while its IOR follows the sampled wavelength. Interior angular integrals are interpolated after dividing by the node IOR squared and then multiplied by the runtime IOR squared, preserving the interpolated return's energy and reverse-path measure.

The coated extension uses sixteen nonuniform F0 nodes around the d-line reference Fresnel value because the native film tint rule includes nonlinear bounds. It interpolates deficits and conductance before reconstructing the symmetric return matrix. Near matched indices, both the cache and closure use the physical film sampler, including its facet-dependent straight-transmission atom. This grid is an approximation, unlike the bare two-endpoint reconstruction. Current coated integrated tests pass; renderer acceptance for this extension is pending.

Active solid transmission requires Thin Wall disabled and constant cache-dependent IOR, dispersion, film, roughness and grating parameters. Base Color, Specular Tint and material weights may vary at runtime. Reflective-only materials retain their generalized tint and anisotropy support. The shared Cauchy helper uses precise division, exact nanometer conversion and a rounded intermediate product so cache construction and the runtime Metal closure agree at the matched-index limit.

These returns are practical approximations to unresolved multiple scattering, not an exact microfacet random walk. Absorption uses the existing reciprocal Fresnel-weighted one-sided model or one bounded tint per two-sided completed return; the latter is not Beer–Lambert absorption. Coated table resolution follows the existing wavelength/resource policy.
