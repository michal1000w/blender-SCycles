# ThinSheet Fast cache integration (v34 staging)

The new cache mode reuses the existing one-sided directional values and projected averages. Ordinary unit-reflector cache requests keep their existing estimator, layout and upload. A ThinSheet request stores a directional missing-energy value `q = R_sheet + T_sheet − E_envelope`; its two exterior-air ports have total normalization `Q = 2*pi*projected_average(q)`. The completed reciprocal component uses the shared microscopic carrier model, not an added lobe pretending to repair the original native carrier's antisymmetric part.

Each propagating facet/order is weighted by the smaller forward/reverse sheet coefficient times its order power. Reflection/transmission coefficients include scalar native-style Fresnel, film and Beer tint. The CPU and Metal builders integrate exactly this model using the same golden-ratio VNDF sequence and all propagating orders, including the direction-dependent zero-order residual. Singular ports use their exact flat-facet order sum. A shared host finalizer averages each fourfold azimuth group, enforcing the physical even x/y symmetry exactly in the finite interpolant while preserving mu-row sums and normalization. Thin mode requires an even azimuth count. Raw energy is validated before accepting the table; this does not establish exact continuum passivity of a finite interpolated table.

The request stores d-line IOR and inverse Abbe. Every wavelength uses the shared Cauchy helper and derives transmission roughness from that wavelength's index with the native ThinWall formula. Chromatic transmission stores raw working-space-to-BT709 RGB and reconstructs the actual sampled-wavelength scalar with the native spectral primaries; scalar gray transmission retains the RGB carrier path. Reflection tint is per scalar channel, so three cache handles represent RGB reflection channels and equal requests deduplicate. No additional device data arrays are introduced.

The runtime material transition remains an explicitly approximate native-compatible blend. It retains the exact native flat limit and cannot simultaneously claim exact full-material reciprocity where the original native incoming-only rough-sheet compensation survives. Only the completed component has the reciprocal envelope/return construction. This is a mathematical Fast model, not a microscopic or Maxwell solution. The prior additive and coarse-matrix envelope experiments remain preserved and are not reclassified as successful production models.

Evidence: `build/tests/performance/thin_sheet_cache_symmetrized_v34/results.json` records 891 actual current CPU-builder checks after the symmetry correction, including white, absorptive gray and spectral coated/dispersion requests, node agreement with the shared estimator, passive surviving-budget checks and cache identity. Host C++, Objective-C++ and standalone Metal shader syntax logs are alongside it.

Fresh cohesive-build actual M5 parity passed all four predeclared cases in `build/tests/performance/thin_sheet_gpu_cache_v34/gpu_cache_comparison.json`: the ordinary control and white, gray and spectral coated/dispersive ThinSheet caches. Every CPU/Metal value and average was explicitly finite. Maximum ThinSheet directional difference was 1.49012e-6 and projected-average difference 8.94070e-8, below unchanged gates 0.002 and 0.0005. `results.json` stores source hashes and the reproducible command. The initial sandboxed device-unavailable attempt was followed by the authorized actual GPU run; device availability is not numerical evidence.

These parity cases use only 4 wavelengths, 6 polar and 8 azimuth samples, and 256 facet samples. CPU cache times were 13.45–23.08ms and Metal times 1.67–3.14ms for the three ThinSheet cases; the first ordinary Metal call took 649ms including initialization. These are small-grid branch checks, not shipping-cache or renderer speed measurements. Shipping preparation uses 24 polar, 16 azimuth and typically 16 wavelength nodes with 512 facet samples. At pitch1150nm this estimates 81.8 million order/facet work units within the 128 million guard; denser coated requests can explicitly retain the uncached native approximation. Linked cache-dependent parameters likewise retain that approximation rather than receiving an unrelated white cache. CPU finalization recomputes averages after azimuth symmetry; Metal preserves its precomputed averages because the symmetry preserves each polar-row sum, then validates normalization.

Actual renderer furnace/material acceptance remains pending. Cache parity alone does not certify the full ThinWall material, its native-compatible transition, or arbitrary parameter ranges.
