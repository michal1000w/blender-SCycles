# Actual Glass polarizer evidence, v43

The immutable v43 package passes [all 39 native Metal checks](../build/tests/python/native_polarizer_render_v43/report.json) with optimized kernels across PT, BDPT and guiding. Malus films, a closed opposing-face slab, physical object rotation, and persistent OFF/ON/OFF reproduce the predeclared radiance references. The earlier [CPU SVM and OSL checks](cycles_polarizer_actual_v42.md) remain v42 evidence; they are not mislabeled as v43 reruns.

[All eight actual Metal shader-integration cases pass](../build/tests/python/native_polarizer_shader_prism_metal_v43/report.json) with unchanged prospective gates. The positive-depth matched-index grating filter gives approximately (0.5000335, 0.5000248, 0.4997974) in PT and BDPT, matching the independent signed spectral sensor integral. The correction identifies the diffraction transmission atom by closure type, so polarization uses the physical transmitted branch. The [v42 failure](../build/tests/python/native_polarizer_shader_prism_metal_v42/report.json) and [independent reference audit](../build/tests/python/native_polarizer_shader_prism_metal_v42/independent_reference_audit.json) remain preserved. No reference fitting or gate relaxation was used. [Pinned package provenance](../build/tests/performance/polarizer_v43_integration_provenance.json) identifies the tested binary independently of subsequent facet-mode working-tree changes.

The [actual v43 gallery](../tests/output/diffraction/polarizer_actual_v43/index.html) combines the native numerical strip with the [complete six-image Metal photographic run (specialization preference 0)](../build/tests/python/native_polarizer_photo_generic_v43/report.json). PT and BDPT each show analyzer OFF, glare-pass and glare-cut orientations. All raw EXRs are finite and undenoised, with 256 fixed samples, no adaptive sampling, and common AgX EV0. The [contact sheet](../tests/output/diffraction/polarizer_actual_v43/actual_polarizer_contact.png) was visually inspected: both modes retain the white rectangular reflection in glare-pass orientation and strongly suppress it in glare-cut orientation while exposing the colored checker floor. Raw hashes and editable Blender links are retained. The earlier partial optimized photographic run is separate from this completed preference-0 run; no optimized-photo completion is inferred.

Fixed top-origin glare ROI x270:370, y190:290 and adjacent-checker ROI x170:250, y190:290 provide descriptive raw linear-luminance ratios in the [gallery manifest](../tests/output/diffraction/polarizer_actual_v43/gallery_manifest.json). These are not new acceptance gates or isolated analyzer transmission measurements: OFF uses legacy scalar dielectric transport, whereas ON activates polarization scene-wide, including multiple Glass bounces. The finite area source leaves residual reflection away from the central Brewster ray. No image-specific exposure, normalization, energy gate or PT/BDPT brightness-identity gate is used.

The [48-case coherent Metal acceptance](../build/tests/performance/coherent_polarizer_render_v42/prospective_gates.json) remains explicitly v42 evidence for the unchanged bounded coherent core. All [six v43 PT persistent coherent checks pass](../build/tests/python/coherent_polarizer_persistent_pt_v43/report.json) with actual Metal kernels with specialization preference 0: source-side single and camera-side parallel filters each follow OFF/ON/OFF without scene reload. This is a minimal v43 regression, not a relabeled 48-case rerun. Coherent connectors require Metal; the preserved CPU attempt was rejected before physics evaluation. Photon mapping is explicitly unsupported. The archived centered-quad IOR1 seam also occurs in stock Blender 5.1.2 and is outside this polarizer scope. These results establish the declared filter and bounded transport cases, not complete arbitrary-object coherent transport. The v42 gallery remains unchanged.

The checkbox is OFF by default and has a substantial opt-in cost in the [warm optimized Metal measurement](../build/tests/performance/native_polarizer_overhead_v43/report.json). At 320×240 and 64 samples, PT median time rises from 0.5593 to 1.0163 seconds (81.7%); BDPT rises from 0.58949 to 1.03514 seconds (75.6%). Each state has one excluded warm run and three measured runs, with the required specialization warmup. Timings include render synchronization and exclude file writing; geometry is unchanged. These are measured costs in this scene, not an image-identity or general performance guarantee.

The [matched default-OFF CD benchmark](../build/tests/python/cycles_diffraction_benchmark_default_off_v43/report.json), at 512×369 and 512 samples, has median 1.83137 seconds versus the retained v37 measurement of 1.777637 seconds, about 3.02% slower. Raw-image comparison is recorded separately; timings alone do not establish image equality.
