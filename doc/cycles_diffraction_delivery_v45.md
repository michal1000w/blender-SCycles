# Actual diffraction and polarization delivery, v45

For the current restored, build-verified checkout, launcher instructions, archived unfinished work and continuation guidelines, see [the extensive handoff](cycles_diffraction_handoff.md). This document retains versioned rendering evidence.

The v45 package adds opt-in coherent direct, one-reflection and ordered two-reflection transport through declared finite ideal-white mirror facets. It also retains the validated Glass polarizer and bounded curved-surface transport. **The original general coherent-transport goal is not complete.** This increment does not establish arbitrary refractive chains, general smooth or rough curved surfaces, volumes, motion, or photon mapping.

The streamed mode removes the former 64-facet/path inventory limit for these mirror paths; work grows linearly with facet count for one reflection and quadratically for two. This is an opt-in geometric-facet model, not unrestricted wave scattering. Coherence uses the documented wavelength carrier with RGB amplitude envelopes and Gaussian coherence, not full broadband spectral coherent transport. The Glass checkbox implements a linear polarizer, not a circular photographic CPL.

The immutable package is [Blender.app](../build/diffraction_delivery_20260928_coherent_facets_2r_v45/Blender.app) ([launcher](../build/diffraction_delivery_20260928_coherent_facets_2r_v45/Launch%20Blender.command)), SHA256 `17b40db7cfdde28e21d81e1715677add4d58f842e6b8f7266927fe6a85bdcd4c`. Two-reflection acceptance uses two finite nonparallel mirror objects, four triangles, two declared 1 mW sources and a first Lambertian detector. Independent double unfolding enumerates direct, both one-reflection routes and the physical ordered two-reflection route; barycentric containment and all three visibility legs are checked. Vector world-dipole fields propagate through independently computed Householder reflections, then an explicit pair sum applies the existing Gaussian coherence envelope. Every reference uses exact saved float geometry, light energy and phase, with no render fitting. Fixed 128 samples, seed 19, adaptive and denoising OFF; prospective mean/RMSE gates 0.0002/0.0008. Actual maximum mean error is **9.25965e-6**, maximum RMSE **0.000405369**. Omitting 2R independently produces phase-π RMSE 0.002954 and distinct-group RMSE 0.001665, so these controls prove the new route matters. Actual/reference contacts use common Standard EV−1, immutable raw EXR hashes and editable Blender links.

The original v45 authoring mistakenly inherited `glossy_bounces=1`; the renderer correctly excluded 2R and failed the tighter gates. Those scenes and reports remain in `coherent_facet_two_v45` and `coherent_facet_two_render_v45`, with [failure provenance](../tests/output/diffraction/coherent_facet_two_v45/authoring_budget_failure.json). Corrected scenes are in `coherent_facet_two_v45_glossy2`; saved readback verifies glossy2, interface events 2, VECTOR, specular connections ON and diffuse 0. References, omission controls and gates are unchanged. This was a fixture-budget failure, not a production physics failure.

Metal provenance: specialization level 0 was requested for the preference-0 runs, but mandatory low-memory specialized scene/evaluation/light-cache pipelines remain enabled on the tested 16 GB device. Preference 0 does not mean all specialization was disabled. Historical directory names, raw worker reports, environment values and hashes remain unchanged.

The retained bounded core supports the documented planar/sphere R/TT/TRT/TRRT cases, with actual v39/v40 images in the [curved transport gallery](../tests/output/diffraction/coherent_progress_gallery_v40/index.html). Native camera/filter numerical tests and finite-area photographic glare suppression have separate provenance; OFF uses legacy scalar dielectric transport, whereas ON enables polarization scene-wide, so ON/OFF photographic ratios are descriptive rather than isolated analyzer-transmission gates. Coherent connectors require Metal; photon mapping is guarded as unsupported.

Warm v43 opt-in polarizer overhead at 320×240/64 spp: PT 0.5593→1.0163s (+81.7%), BDPT 0.58949→1.03514s (+75.6%), one excluded warm run and three measured runs. Matched default-OFF CD median v43 is 1.83137 s versus retained v37 1.777637s (+3.02%). [Timing provenance](cycles_polarizer_actual_v43.md) records required warmup. Final v45 default-OFF CD median is **1.855122 s** (measured runs 1.89116/1.83188/1.85512 s), **4.36%** above retained v37. The 74.0818 s initial warmup is excluded. [Final benchmark](../build/tests/python/cycles_diffraction_benchmark_default_off_v45/report.json) and [raw comparison](../build/tests/performance/cd_default_off_v45_vs_v37.json) retain provenance: raw RMSE **6.04818e-8**, maximum error **3.33786e-6**. No scene-specific result is a general performance guarantee.

The [two-reflection timing record](../build/tests/performance/coherent_facets_v45_render_timings.json) separates cold first-mode initialization/compilation (PT 73.88 s, BDPT 340.61 s, guiding 238.88 s) from initialized subsecond cases. A same-process PT repeat took 0.371061 s at 16×16/128 spp; this is a single diagnostic, not a median or a scalable performance claim. These preference-0 cold runs retain the mandatory low-memory specialized pipelines. The initial empty-output-directory runner attempt is preserved separately from the completed batch.
